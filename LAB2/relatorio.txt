% --- SEÇÃO 2: OBJETIVO ---
\section{Objetivo}
O objetivo deste trabalho é desenvolver um programa em linguagem C para ler uma sequência de 20 chaves inteiras contidas em um arquivo texto (\texttt{chaves.txt}) e inseri-las dinamicamente em uma Árvore Binária de Busca (ABB). A estrutura de cada nó armazena a chave, a altura e os ponteiros para as subárvores esquerda e direita.

Após a construção completa da árvore, o programa percorre a estrutura de forma recursiva para calcular e atualizar o campo de altura de cada nó. Por fim, o sistema exibe no console os percursos em pré-ordem e em ordem simétrica, imprimindo em cada elemento a chave e sua altura calculada no formato \texttt{chave(altura)}, garantindo a correta liberação de toda a memória alocada ao término da execução.

% --- SEÇÃO 3: ESTRUTURA DO PROGRAMA ---
\section{Estrutura do Programa}

\begin{itemize}
    \item \textbf{Estrutura de Dados (\texttt{No}):} Contém os campos inteiros \texttt{chave} e \texttt{altura}, e dois ponteiros autorreferenciais (\texttt{esq} e \texttt{dir}) para as subárvores filhas.
    \item \textbf{Módulo de Alocação (\texttt{criaNo}):} Aloca memória dinamicamente com \texttt{malloc}, valida a alocação, inicializa a altura como 0 e os ponteiros como \texttt{NULL}.
    \item \textbf{Módulo de Inserção (\texttt{insere}):} Insere recursivamente cada chave mantendo as propriedades da ABB (chaves menores à esquerda, maiores à direita).
    \item \textbf{Módulo de Cálculo de Altura (\texttt{calculaAltura}):} Navega recursivamente até as folhas e atualiza o campo \texttt{altura} de cada nó como $1 + \max(\text{alturaE}, \text{alturaD})$, considerando altura $-1$ para ponteiros \texttt{NULL}.
    \item \textbf{Módulos de Percurso (\texttt{preOrdem} e \texttt{simetrica}):} Percorrem a árvore recursivamente exibindo as chaves e suas respectivas alturas formatadas como \texttt{chave(altura)}.
    \item \textbf{Módulo de Liberação (\texttt{liberaArvore}):} Percorre a estrutura em pós-ordem desalocando a memória de cada nó com \texttt{free}.
\end{itemize}

% --- SEÇÃO 4: SOLUÇÃO E CÓDIGO ---
\section{Solução e Código}
O código abaixo realiza a leitura do arquivo \texttt{chaves.txt}, montagem da árvore, cálculo das alturas, exibição e liberação de memória:

\begin{lstlisting}
#include <stdio.h>
#include <stdlib.h>

struct no {
    int chave;
    int altura;
    struct no *esq;
    struct no *dir;
};

typedef struct no No;

No *criaNo(int chave) {
    No *novo = (No *) malloc(sizeof(No));
    if (novo == NULL) {
        printf("Erro ao alocar memoria!\n");
        exit(1);
    }
    novo->chave = chave;
    novo->altura = 0;
    novo->esq = NULL;
    novo->dir = NULL;
    return novo;
}

No *insere(No *raiz, int chave) {
    if (raiz == NULL) {
        return criaNo(chave);
    }
    if (chave < raiz->chave) {
        raiz->esq = insere(raiz->esq, chave);
    }
    else if (chave > raiz->chave) {
        raiz->dir = insere(raiz->dir, chave);
    }
    return raiz;
}

int calculaAltura(No *raiz) {
    if (raiz == NULL) {
        return -1;
    }
    int alturaE = calculaAltura(raiz->esq);
    int alturaD = calculaAltura(raiz->dir);
    if (alturaE > alturaD) {
        raiz->altura = alturaE + 1;
    }
    else {
        raiz->altura = alturaD + 1;
    }
    return raiz->altura;
}

void preOrdem(No *raiz) {
    if (raiz != NULL) {
        printf("%d(%d) ", raiz->chave, raiz->altura);
        preOrdem(raiz->esq);
        preOrdem(raiz->dir);
    }
}

void simetrica(No *raiz) {
    if (raiz != NULL) {
        simetrica(raiz->esq);
        printf("%d(%d) ", raiz->chave, raiz->altura);
        simetrica(raiz->dir);
    }
}

void liberaArvore(No *raiz) {
    if (raiz != NULL) {
        liberaArvore(raiz->esq);
        liberaArvore(raiz->dir);
        free(raiz);
    }
}

int main(void) {
    FILE *arquivo;
    No *raiz = NULL;
    int chave;

    arquivo = fopen("chaves.txt", "r");
    if (arquivo == NULL) {
        printf("Erro ao abrir o arquivo chaves.txt\n");
        return 1;
    }

    while (fscanf(arquivo, "%d", &chave) == 1) {
        raiz = insere(raiz, chave);
    }
    fclose(arquivo);

    calculaAltura(raiz);

    printf("Pre-ordem: ");
    preOrdem(raiz);
    printf("\n");

    printf("Simetrica: ");
    simetrica(raiz);
    printf("\n");

    liberaArvore(raiz);
    return 0;
}
\end{lstlisting}

\section{Observações e Conclusões}
\begin{itemize}
    \item \textbf{Análise do Resultado:} A impressão dos dados no percurso em Ordem Simétrica é exibida de forma estritamente crescente, o que confirma visualmente que a árvore binária de busca foi construída corretamente.

    \item \textbf{Instruções de Compilação:} O código foi compilado em ambiente GCC através do comando:
    \begin{verbatim}
    gcc -Wall -std=c99 main.c -o arvore
    ./arvore
    \end{verbatim}
    Certifique-se de manter o arquivo \texttt{chaves.txt} na mesma pasta do executável.
    \item \textbf{Resultados dos Testes:} O programa executou perfeitamente todos os requisitos solicitados, realizando a leitura do arquivo, o cálculo pós-inserção e a limpeza de memória via desalocação dinâmica sem vazamentos.
\end{itemize}
